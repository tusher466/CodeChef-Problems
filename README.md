## ⚡ Approach

For each problem, I try to follow these general steps:

### 1. Understand the Problem

First, I carefully read the problem statement and identify:

* What is given?
* What needs to be calculated?
* What are the constraints?
* What should be printed?

### 2. Find the Logic

I try to identify the mathematical observation, algorithm, or data structure required to solve the problem.

### 3. Analyze Complexity

Before implementing the solution, I consider:

* **Time Complexity**
* **Space Complexity**

For example:

```text
Time Complexity: O(N)
Space Complexity: O(N)
```

### 4. Implement in C++

After finding the approach, I implement the solution using C++.

### 5. Test the Solution

I test the solution using:

* Sample test cases
* Edge cases
* Small inputs
* Large inputs
* Custom test cases

### 6. Submit to CodeChef

Finally, the solution is submitted to CodeChef and tested against the official test cases.

## 📊 Complexity

I try to keep the solutions efficient enough to satisfy the constraints of each problem.

Some commonly used complexities include:

| Complexity   | Example                              |
| ------------ | ------------------------------------ |
| `O(1)`       | Mathematical calculations            |
| `O(log N)`   | Binary Search                        |
| `O(N)`       | Array traversal                      |
| `O(N log N)` | Sorting                              |
| `O(N²)`      | Nested loops for smaller constraints |
| `O(N + M)`   | Graph or combined data processing    |

The required complexity depends on the constraints of the individual problem.

## 🚀 How to Run the Solutions

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

### 2. Open the Repository

```bash
cd YOUR-REPOSITORY
```

### 3. Compile a Solution

For example:

```bash

```

### 4. Run the Program

